# 🏝️ Rust Island - Companion Suite & Discord Utilities

A vibrant, tropical beach-themed companion utility suite built for Rust survival teams and Discord gaming communities. Manage raid expenses, calculate recycler returns, run crate timers, combine crop genetics, and maintain door code registries—all with local browser auto-saving and a built-in mini-game!

---

## 🌊 Key Features

* 💥 **Raid Cost Calculator:** Instant material breakdowns (Sulfur, Charcoal, Metal, LGF) for C4, Rockets, and Satchels needed for doors and walls.
* ♻️ **Recycler Yield Calculator:** Compute exact Scrap, HQM, and Metal Fragment returns from recycled components (Gears, Tech Trash, Pipes, etc.).
* ⏱️ **Monument Crate Timers:** Audio-assisted 15-minute countdown timers for Oil Rig and Cargo Ship locked crates.
* 🌱 **Gene Combiner:** Predict child genetics for hemp and tea cross-breeding setups.
* 📋 **Team & Code Registry:** Track door codes, airlocks, and raid wishlist notes with automatic local browser persistence.
* 🐤 **Flappy Bird Mini-Game:** Integrated procedural HTML5 canvas mini-game to pass time during night cycles, crafting queues, or raid defenses!

---

## 🚀 Deployment & Usage

### Option 1: Web Interface
1. Download `index.html` from this repository.
2. Open `index.html` in any modern web browser or embed it into Discord via Discord Activity/Webview.
